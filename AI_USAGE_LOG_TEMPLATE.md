# AI Usage Log Template

Use this template to document each material use of generative AI in the CodeKids project. Create one entry per task or logically related interaction. Replace all placeholder text before adding an entry to a project log or thesis appendix.

## Completion Checklist

- [ ] The date, tool, and model are recorded.
- [ ] The purpose and assistance type are specific.
- [ ] Every affected file or artifact is listed.
- [ ] The prompt is summarized without sensitive information.
- [ ] The adopted AI contribution is clearly identified.
- [ ] Personal review, adaptations, and rejected suggestions are documented.
- [ ] Verification and limitations are recorded.
- [ ] The entry is written entirely in English.
